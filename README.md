# Moodium Pocket · 手机版

没有 Vision Pro 时的补充体验：手机吸在枕头形状的感官底座中间，按压底座让手机轻微摆动，陀螺仪把每一次摆动变成一次“捏捏”，触发和 visionOS 版一致的世界、粒子和 Moodi 救援故事。

用 Xcode 16.3+ 打开 `Moodium.xcodeproj`，选择 iPhone / iPad 运行（iOS 17+，横屏）。真机需在 Signing & Capabilities 里选自己的 Team。仓库里的 `.usdz` 用 Git LFS 存储，克隆后先 `git lfs pull`。

## 体验流程

1. **开场**：沿用 Unity 的开场动画（带透明通道），边缘羽化后叠在烟紫色房间背景上；播完后 Logo 上移，出现和 visionOS 一样的玻璃按钮：选语言（中文 / English）。不再问有没有底座：底座和屏幕两种捏法一直同时生效。
2. **选关**：移植 `WorldCarouselSelectionController` 的轮播参数：两座世界岛屿（CandyWorldUI / NatureWorldUI），侧边缩到 70 %、透明 55 %、偏转 20°，切换 0.35 s 缓出；背景是所选世界全景图的模糊版，岛屿用全景图做环境光。Moodi 在旁边说一句话，底部是移植的玻璃滑块 `GlassSlideToEnter`（糖果粉 / 自然绿主题）。
3. **捏捏救援**（移植 `MoodiRescueDirector` 和 K1–K10 中英文配音）：
   - 世界 360° 全景做背景，手机摆动时有轻微视差；
   - Moodi 飞进来、脚下一滑掉进捏捏枕头（CandySoft / NatureSoft），闷声求救；
   - 每次按压：枕头像果冻一样压扁、回弹、晃两下，并向被按的一侧倾斜；从枕头里喷出 Unity 的道具模型（巧克力、饼干、爱心、星星、马卡龙 / 叶子、花、蘑菇）；
   - **手机特有的玩法**：道具和小糖珠受手机真实重力影响，晃动底座它们就跟着滚；撞到屏幕边缘会弹回，撞击点沿屏幕边缘亮起一道光、溅出水花，同时有轻微震动和音效；落在枕头上的道具会在下一次按压时被弹起来；拿起手机用力晃会把所有东西撒开；
   - 能量环完全照 visionOS 设计稿：40 颗点、呼吸的头部点、20/50/80/100 % 四颗礼物菱形（点亮时放大并扩散波纹）、满能量 3 秒后淡到 40 %、8 秒没按压淡到 60 %；
   - 环境粒子随能量变化（按 `CandyFrostParticleController` 的曲线）：糖果世界糖霜越来越密，接近 100 % 变成糖雪；自然世界落叶、蒲公英和萤火虫；
   - Moodi 的声音经过低通滤波，能量越高越清楚；20/50/80 % 各说一句，连续按压随机鼓励，12 秒没按会催一下；
   - 100 %：枕头鼓起后“啵”地消失，Moodi 跳出来转圈，糖果雨 + 彩珠落下，然后屏幕正中间出现一张小卡片：“许个心愿”或“再捏一次”。

## 首页与导航（2026-11-01）

- **首页**（`Home/HomeView.swift`）：左边是平面 Moodi（`Home/FlatMoodi.swift`：表情跟着今天的心情变，会漂浮、呼吸、轻轻摇摆、每隔几秒眨眼，身后有心情颜色的光晕和闪光，点它会被捏扁、跳一下、笑并冒出小星星），上面是按时间的问候和一句话，下面是“测测今天的心情”。右边三张玻璃卡：**捏捏小世界**（进选关）、**许愿风铃**（显示已经挂了几个）、**心情记录**（每次进出世界的心情变化、停留时间和捏的次数，只存在本机）。
- 第一次打开：开场动画 → 选语言 → 首页；之后再打开，开场动画放完直接到首页（语言可以在设置里改）。
- 返回：世界 → 选关 → 首页（选关页左上角有首页按钮）。只有救出 Moodi 之后离开、并且今天测过心情时，才会再问一次“现在呢？”。
- 今天的心情会记到当天结束，重开 App 也还在。
- 世界里：去掉了右下角的“退出世界”（左上角返回就是退出）；四个玩法按钮改成右边竖排；去掉了左上角的世界名称和“第几件礼物”提示；切换玩法的提示放在能量环右边。
- **挤出动画换成没有洞的软模型**（对应 Unity world-fix-1030）：枕头用原版 `CandySoft` / `NatureSoft`，Moodi 从表面慢慢升起来。原版模型和之前开洞版的位置用网格配准对齐（`MoodWorld.wholeSoftFit`），Moodi 站在开口附近 1.5 cm 内表面的最高点。开洞版模型文件还在仓库里，但已经不用了。救出后 Moodi 不再放大到 1.25 倍。

## 第一批新内容（来自 Unity `codex/world-dock-1031` 分支）

- **心情签到**（`Mood/`，移植 `MoodCheck`）：开场选完语言后，Moodi 问“你现在的心情怎么样？”。在彩色圆盘上拖动 Moodi（左右 = 不太好 / 还不错，上下 = 有点累 / 精力充沛），或直接点开心 / 平静 / 一般 / 低落 / 烦躁。确认后推荐世界和玩法，可以跳过。测心情只有一个入口：首页 Moodi 下方的“测测今天的心情”（测过后变成“现在：开心 · 再测一次”）。选关页标题下只读地显示今天的心情和 Moodi 的建议，不再放第二个测心情按钮；推荐的世界名字前有“Moodi 推荐”标签。离开世界时再问一次“现在呢？”，显示进入前 → 现在的对比、停留时间和捏的次数。记录只存在本机（`MoodLog`）。
- **三种捏法**（`Squeeze/SqueezeModes.swift`，移植 `SqueezeTuning` / `RhythmScorer` / `BreathScorer` / `EnergyAssist`，能量计算和 Unity 一样按 100 分）：
  - 自由：和以前一样，每按一下都算；
  - 节奏：光圈每拍缩到能量环上，碰到时按一下。按准有音效和水花，连击最多 8 颗珠子，每 8 连击额外奖励；连续 4 次没按准，节拍就改为跟着你的节奏；
  - 呼吸：按住底座或屏幕吸气（播 4 秒吸气声，能量环外的光慢慢涨，3–5.5 秒是最舒服的区间，变绿），松开呼气（播 5 秒呼气声，枕头喷出道具）。
  - 氛围层（`Squeeze/ModeAtmosphere.swift`，2026-11-04）：自由模式晃感官袋时，枕头四周亮起光晕，并持续冒出星光（`SparkleScene.setFlow`），晃得越用力越多；节奏模式屏幕四边跟着节拍轻轻亮一下，按准时再闪一次，每下都会提示"完美 / 不错 / 早了一点 / 晚了一点"，连击时依次响起本世界的三个风铃音；呼吸模式四周略微压暗，枕头上方的光随吸气升起、随呼气落下，能量环下方的提示条显示"吸气 1、2、3 → 松开，呼气"和已完成的呼吸次数。持续晃袋子也算在玩：能量环不会变暗，Moodi 也不会问"还在吗"。
  - 心情会推荐起始玩法（开心 / 低落 → 节奏，平静 / 烦躁 → 呼吸），左下角的玻璃按钮可以随时切换，“玩法”按钮说明三种玩法。75 秒后节奏和呼吸会慢慢给更多能量，不会卡住。
- **四件礼物**（`Squeeze/GiftGarden.swift`，按 Unity 的奖励表）：20 / 50 / 80 / 100 % 时在枕头两侧长出来，并播放生长音效（`grow_candy` / `grow_nature`）。糖果世界：糖果三重奏 → 曲奇和巧克力 → 小糖果屋 → 糖果屋；自然世界：小花和蘑菇 → 杜松 → 小橡树 → 松树。糖果屋和树的模型从 Unity 的 FBX 转出（糖果屋减面到约 2 万面）。
- **摸摸 Moodi**：点屏幕上的 Moodi，它会播放 Touched 动画（3D 版）或者被捏一下（2D 版），出一点闪光；救出来以后摸它，有时会说“好舒服～”。
- **选关语音**：滑到某个世界时，Moodi 说 S1c / S1n（“来糖果世界玩吧，甜甜的哦～”），如果是心情推荐的世界就说 S2（“今天的你，会喜欢这里哦～”），同一个世界 20 秒内只说一次。

## 第二批：许愿风铃（`Wish/`，移植 `WishChime` / `WishPresetPanel` / `WishWritingTimeline`）

- 入口：救出 Moodi 后卡片上的“写一张心愿，挂成风铃”，或者选关页右上角的“许愿风铃”。
- 写字：中间是 8.5 × 27.5 比例的纸条（糖果世界粉色、自然世界牛皮纸色，带叶子装饰），挂在 Unity 风铃模型渲染出来的铃铛下面，用手指直接写。笔迹格式、采样间距（1.5 mm）、每笔最多 74 个点、总共最多 4000 个点、墨水和光晕的颜色与粗细都和 visionOS 一样，写字时有沙沙声。
- 预设心愿：左边 2 × 3 的玻璃小签（平安喜乐、天天开心、好事发生、身体健康、烦恼退散 / 自己写），选了以后按真实笔顺一笔一笔写出来（2.2–3.4 秒），写完风铃轻响、放飞按钮跳两下；写完还可以在下面签名。
- 放飞：点“放飞”，或者**把手机往上托一下**；纸条缩回铃铛下面，沿弧线飞到顶上的绳子挂好。“重写”或者**摇一摇手机**会把纸条擦掉。
- 风铃：挂好的心愿沿屏幕顶部排成一排，**倾斜手机它们会跟着摆**，摆得厉害会自己响；点一下响一下，摇一摇全部响起来。
- 保存：`Application Support/wish_chimes.json`，格式和 Unity 的 `WishChimeRecord` 一样（只存在本机）；下次进来风铃还在，Moodi 会说“你的风铃还在这里等你呢”。
- Moodi 语音：B3、B5、B6、B7、B8（B4 讲的是捏手指写字，手机上用不到）。

## 按压识别（`Squeeze/PressSensor.swift`）

- 读取 Core Motion 的重力方向和旋转速率，按当前横屏方向换算到屏幕平面；
- **自动认摆动方向**（`Squeeze/PressSensor.swift`）：感官袋只接受左右按，手机只会沿一个方向轻微摆动，但手机怎么摆在袋子上不一定。所以从陀螺仪学出最近转动的主轴（只用明显在动的样本，约 1.5 秒记忆），沿这个方向跟踪倾斜角（来自融合后的重力方向）和转速；开始时假设绕屏幕竖轴，第一下按压后就会对准，主轴转过 20° 会重新校准静止位置；
- **像“测距仪”里的水平仪一样连续跟随**（`Squeeze/RockDetector.swift`）：不设“按到多少才算”的门槛。手机倾斜多少，屏幕里的枕头就实时压下去多少（0.6° 压到底）。自由模式下，手机只要在来回动，进度条就按摆动快慢连续上涨（最多 12 点/秒，满格 100）。门槛是现场测出的这台手机自己的传感器噪声（0.12–0.6°/s 之间自动调），匀速的慢慢下沉会被减掉，不涨进度；
- 在连续进度之外，每次明显的捏捏还会触发粒子、震动、音效，再额外加一点能量：从上一次转向的位置往外摆过 0.15°、并且是离开静止位置的方向（不是回弹），就算一次捏捏；摆动速度要超过 0.8°/s，慢慢下沉不算。力度看这一摆的最快速度（0.8°/s → 0.2，18°/s → 1）。用力按完 0.4 秒内，下一下要有上一下四分之一深才算，袋子的余震不会多算；
- 左右交替按、同一侧连续按都能逐下计数，两次之间最短 0.12 秒；静止 0.3 秒后重新起算，静止 0.6 秒后静止位置慢慢跟随（手机陷进袋子、袋子塌下去都不影响）；
- 用力按完松手，袋子回弹到另一侧时，要超过上一下深度的 1/4 才算新的一下，避免回弹被多算；
- 用力晃动（线性加速度 > 1.1 g）不算按压，而是把道具撒开，并重新记住静止位置；
- App 自己的震动会让传感器短暂忽略，避免震动被误判为按压；
- 设置里的底座灵敏度（灵敏 / 适中 / 稳重）把上面的角度和速度乘以 1 / 1.45 / 2.1（灵敏就是未调档时的原始数值，适中和稳重依次更迟钝）。**这些数值是按模拟数据定的，需要在真实感官袋上调**，都在 `RockDetector` 顶部。
- 模拟测试：`Tools/rock-sim/main.swift` 用造出来的倾斜曲线（交替按、同侧连按、轻按、用力按带回弹、静置噪声、慢慢下沉、斜放、呼吸按住）检查计数。运行：`swiftc -O Tools/rock-sim/main.swift Moodium/Squeeze/RockDetector.swift -o /tmp/rock-sim && /tmp/rock-sim`
- **按住识别**（呼吸模式用）：倾斜离开静止位置超过 0.5°、持续 0.1 秒算“按住”，回到 0.25° 以内 0.12 秒算“松开”；呼吸模式里按住期间静止位置不跟随，按住超过 15 秒会重新校准。
- **感官袋引导**（`Squeeze/BagGuide.swift`）：第一次进入任意世界时，Moodi 掉进袋子的开场先暂停，弹出引导：侧面图示“感官袋平放、手机屏幕朝上放中间、左右按袋子”。按袋子时，图里的手机会像水平仪一样跟着真手机实时晃（角度放大 9 倍），按的那一侧小手会亮起；“试一试”条按满会震一下并显示“感觉到了”。点“开始”后才开始开场，以后不再自动弹出，可以在“玩法”卡里点“感官袋怎么放？再看一遍”重新打开；
- **屏幕按压和底座同时生效**：按住屏幕枕头被压下，松开即一次捏捏，力度取决于按住时长，方向取决于按在屏幕左边还是右边。手指按在屏幕上、以及松开后 0.35 秒内，陀螺仪的摆动不计数，免得一次按压算两次；呼吸模式里谁先开始按住，就由谁的松开来结束这口气。

## 已知限制

- 字体：Unity 里的阿里巴巴普惠体只有 TextMeshPro SDF 图集，没有 TTF，这里用系统圆体代替；有 TTF 后放进工程并改 `Font.moodium` 即可。
- Unity 的软体变形、Shader（如果冻材质）无法直接迁移，枕头的形变是缩放弹簧近似。
- Moodi 用的是 2D 表情图做动画，没有导入骨骼动画模型。

## 3D Moodi 挤出救援
已接入 Moodi.usdz、CandySoft_Mouth / NatureSoft_Mouth 及对应骨骼 JSON；旧软垫与 2D Moodi 保留回退。启动参数 `-MoodiSprite YES` 可强制对比旧流程。
新流程包括飞入、掉入洞口、小芽求救、随能量渐进挤出、快眨、洞口收拢与跳出、再救一次。软垫倾斜 38°，按压缩放幅度为旧版 0.6；语音 RMS 驱动求救动作，静音时使用周期摆动。传感器、能量公式和礼物阈值未修改。
验证：iOS 模拟器编译；包内 Mac SceneKit 预览工具校验模型与动画。真机完整流程、后台恢复、iPad 布局和 GPU/内存性能仍需实测，不能以编译成功替代。

## iPhone Duo（折叠屏）

- **桌面姿态放烟花**：Duo 内屏半折、折痕横在中间（像小笔记本一样立在桌上）时，捏捏世界一分为二：下半屏是枕头、Moodi、能量环和所有按钮，上半屏变成夜空。每次挤压，火花从 Moodi 嘴边升起、越过折痕，在上半屏炸开；长出礼物时连放三发，救出 Moodi 时放一整轮（糖果世界有爱心烟花）。开合角度越大，烟花飞得越高。展平、合上或在普通 iPhone 上，一切和原来一样。
- **代码位置**：`Moodium/Foldable/Fold.swift`（折叠状态与上下两半的计算）、`Moodium/Foldable/FireworksSky.swift`（烟花与上半屏天空）；`SqueezeView` 按"舞台区 / 天空区"两个矩形摆放内容。
- **编译要求**：折叠角度接口（`onHingeChange`、`reservedRegions(kind: .division)`）只在 iOS 27.1 SDK 里有，需要用 **Xcode 27.1** 编译。工程只在 iOS 27.1 及以上 SDK 下打开 `MOODIUM_DUO` 编译开关，用旧版 Xcode 编译时这部分代码不参与，应用照常运行。
- **屏幕方向（避免被缩成小窗）**：只声明横屏的应用在 Duo 内屏竖着拿或半折时，会被系统缩成屏幕中间的一个横向小窗。所以 Info.plist 同时列出横屏和竖屏，再由 `Moodium/App/OrientationPolicy.swift` 在运行时决定：普通 iPhone 和 Duo 外屏这种细长屏幕仍然只能横屏，Duo 内屏这种接近方形的屏幕可以竖屏。开合 Duo（应用换到另一块屏幕）时会重新判断。
- **避开折痕**：Duo 内屏竖着拿时，不管展平还是半折，折痕都横在屏幕中间。每个页面都按"上看下点"分两半，内容不压在折痕上：开场动画、首页 Moodi、选世界的小岛、心情盘、风铃和纸条在上半屏；卡片、滑动进入、问题和快捷选项、心愿选项和放飞按钮在下半屏；捏捏世界上半屏是烟花天空，下半屏是舞台。设置、玩法、心情记录、感官袋引导这些弹窗会整个落到下半屏，放不下时自动缩小。
- **代码位置**：折痕位置在 `Moodium/Foldable/Fold.swift` 的 `Crease`（优先读系统给的折痕区域，读不到时按屏幕中间算），通过环境值 `\.crease` 传给所有页面；`CreaseStack` 负责上下两半排版，`.offCrease()` 让弹窗避开折痕。Mac 测试版用竖屏窗口（669x951）模拟，`CREASE_LINE=1` 会把折痕标成红条。
- **边距**：所有页面全屏绘制，边缘按钮按机型统一留边（`Moodium/Design/ScreenMargins.swift`），刚好避开灵动岛和圆角。
